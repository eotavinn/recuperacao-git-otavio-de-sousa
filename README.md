* **Linguagem utilizada:** C

## Descrição Breve
Um programa em console simples que permite cadastrar o nome, idade e nota de um aluno, exibindo os dados formatados na tela logo em seguida. O objetivo principal do projeto é demonstrar o fluxo de versionamento com Git/GitHub.

## Como executar o programa
1. Certifique-se de ter um compilador GCC instalado.
2. Abra o terminal na pasta do projeto.
3. Compile o código com o comando: `gcc main.c -o programa`
4. Execute o programa: `./programa` (Linux/Mac) ou `programa.exe` (Windows).
